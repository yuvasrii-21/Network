# 1. Enterprise Campus Network Design and Implementation

## Purpose

Design and implement a secure, scalable enterprise LAN with proper network segmentation and inter-VLAN communication.

### Project Description

Designed a campus network consisting of HR, Finance, IT, and Sales departments using Cisco Packet Tracer. Configured VLANs, trunk links, Router-on-a-Stick, Spanning Tree Protocol (STP), and IPv4 subnetting to provide efficient traffic management and network stability. Verified connectivity using Ping and Traceroute.

### Technologies Used

- Cisco Packet Tracer
- TCP/IP
- IPv4
- VLAN
- Trunking
- STP
- Router-on-a-Stick

### Skills Covered

- TCP/IP
- OSI Model
- IPv4
- Basic Subnetting
- Routing & Switching
- VLAN

- STP
- Port Configuration
- LAN Design
- Ping
