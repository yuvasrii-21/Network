# Enterprise Campus Network Design and Implementation

## Purpose

Design and implement a secure and scalable enterprise LAN for multiple departments with proper network segmentation and inter-VLAN communication.

## Project Description

Designed a campus network consisting of HR, Finance, IT, and Sales departments using Cisco Packet Tracer. Configured VLANs, trunk links, Router-on-a-Stick, Spanning Tree Protocol (STP), and IPv4 subnetting to ensure efficient traffic management and network stability. Verified connectivity using Ping and Traceroute.
